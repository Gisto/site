Gisto

Gisto is a cross-platform snippet manager for GitHub Gists and GitLab Snippets. Search, tag, edit, and share code snippets.

  • Advanced search and tagging
  • Syntax highlighting with Monaco editor
  • Quick snippet actions and copy to clipboard
  • Light and dark themes
  • Local storage mode — no account required
  • Available as a web app at app.gisto.org
  • MIT open source

Download from GitHub Releases or install via Homebrew: brew install --cask Gisto/tap/gisto
