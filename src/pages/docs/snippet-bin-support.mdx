## Overview

[Snippet-Bin](https://github.com/sanusart/snippet-bin) is a **self-hosted**, open-source snippet management application inspired by the GitHub Gists API. Gisto supports Snippet-Bin as a first-class provider, giving you the same Gisto experience with full data ownership.

## Why Use Snippet-Bin?

- **Self-hosted & private** — Your snippets never leave your own server. No third-party dependency.
- **Full control** — You own the data, the database, and the uptime. No rate limits, no unexpected API changes.
- **Docker-ready** — Deploy with a single `docker run` command behind your own domain or VPN.
- **API-compatible** — Snippet-Bin's API is inspired by the GitHub Gists API, making it a natural fit for Gisto.

## Connecting Your Snippet-Bin Instance

1. Open Gisto login page
2. Select "Snippet-Bin" as your provider
3. Enter your Snippet-Bin instance URL (e.g., `https://snippet-bin.yourdomain.com`)
4. Insert your Snippet-Bin API token

## Working with Snippet-Bin

Once connected, your Snippet-Bin snippets will appear in Gisto. You can:

- **Search and filter** snippets using the same search interface
- **Create new snippets** on your Snippet-Bin instance directly through Gisto
- **Edit existing snippets** stored on Snippet-Bin
- **Tag and organize** your snippets the same way as with other providers
- **Star your favorite snippets**

All operations are synced in real-time with your Snippet-Bin instance.
