## Overview

Gisto supports local snippet storage using IndexedDB, allowing you to create and manage code snippets without requiring a connection to GitHub or GitLab. Your snippets are stored in your browser's local database.

This is a **local-only** mode - snippets are stored in your browser and **will not sync** across devices or to any cloud provider. To move snippets between devices or back them up, use export and import as JSON from Settings.

## Using Local Storage Mode

To use local storage mode, simply launch Gisto and choose to skip authentication or select local storage. No account required.

## Benefits of Local Storage

- **No account required**: Use Gisto without connecting to any external provider
- **Offline Access**: Access your snippets without internet connection
- **Privacy**: Your snippets are stored in your browser's local database
- **Export/Import**: Export and import your snippets as JSON files from Settings - this is the only way to move snippets between devices or back them up
