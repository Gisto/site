---
title: 'How does Gisto sync with GitHub Gists & GitLab? Is my data secure?'
author: Sasha Khamkov
category: 2. F.A.Q.
published: 2026-05-29
---

Gisto connects directly to the official GitHub & GitLab APIs via Personal Access Tokens. Gisto only saves the Access token in your local storage and nothing else. Authentication supports two modes: GitHub/GitLab access token or local storage mode using IndexedDB without any account.
