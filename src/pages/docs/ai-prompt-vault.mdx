## Overview

Gisto supports multiple languages with machine-generated translations (experimental and not fully implemented yet). You can change the language in the settings.

Gisto also provides an AI-assisted tool inside snippet descriptions. If you add your AI provider API key in settings, you can click the **AI** description helper to automatically generate descriptions and tags for your snippets.

## Tagging & Prompt Categorization

Organize your snippets by using customized tag categories. By tagging your snippets with custom markers, you can filter and query them efficiently.

## Prompt Variable Interpolation

You can write prompt templates with clearly defined parameter variables using curly braces:

```markdown
You are a senior frontend engineer. Refactor the following React component to resolve performance leaks.

Input Code:
{{ReactComponent}}

Desired styling framework:
{{CSSFramework}}
```

## AI Assistant Descriptions

Gisto provides an AI-assisted tool inside snippet descriptions. If you add your AI provider API key in settings, you can click the optional **AI** description helper. Gisto will analyze the contents of your code file or document to automatically suggest clean descriptions and tags.
