## Overview

Gisto supports structured snippet types beyond plain code snippets. Each type provides a dedicated editor and view, so you can keep tasks, boards, reference docs, and study material alongside your regular snippets.

## Available types

### Snippet

The default multi-file snippet for code, text, and other files. Use it for source files, configs, notes, and anything that fits a regular snippet.

### To-do list

A checklist snippet for task tracking.

- Add, edit, reorder, and remove items
- Check items off as you complete them
- Progress is stored as a Markdown checklist

### Kanban board

A board snippet for organizing work in columns.

- Create columns and cards
- Add card descriptions, labels, and priorities (low, medium, high)
- Move cards between columns to track progress

### Doc

A structured documentation snippet for references and procedures.

- Organize content into sections and entries with titles, prose, and code blocks
- Use **reference** mode for grouped lookups
- Use **ordered** mode for step-by-step procedures with completion tracking

### Flashcards

A study snippet for memorization and review.

- Create cards with a front and back
- Optionally add multiple-choice answers and time limits
- Review cards with spaced-repetition ratings (again, hard, good, easy)

## Creating a typed snippet

1. Click **New Snippet**
2. Choose the snippet type
3. Fill in the content using the type-specific editor
4. Save the snippet

Typed snippets are stored with your snippet data and work with your connected provider like regular snippets.
