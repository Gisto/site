title: Do you use backend server?
author: Sasha Khamkov

---

Gisto is a client-side application that interacts with GitHub Gists, GitLab Snippets APIs, or a local in-browser database (IndexedDB). It relies on the providers' back-ends for storing and managing snippets, rather than having its own dedicated server-side infrastructure.

Gisto stores nothing except its own configurations and your access token (saved permanently in local storage until you log out or it expires).
