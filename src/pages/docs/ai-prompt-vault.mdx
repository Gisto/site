## Overview

Modern engineering involves managing not just code blocks, but also structured LLM parameters, prompt templates, and system instructions for AI assistants like Claude, ChatGPT, or IDE wrappers like Cursor. 

Gisto makes organizing your prompt directories elegant and highly structured.

## Tagging & prompt categorization

Organize your prompt directories by using customized tag categories. By tagging your prompts with custom markers, you can filter and query them in milliseconds:

* `#system-prompts`: For general guidelines and instructions given to AI agents.
* `#few-shot`: For high-quality examples containing desired input/output structures.
* `#cot`: For chain-of-thought system prompts.

## Prompt variable interpolation

Because Gisto includes complete Markdown rendering, you can write prompt templates with clearly defined parameter variables. 

For example, write prompt skeletons using traditional curly braces:

```markdown
You are a senior frontend engineer. Refactor the following React component to resolve performance leaks.

Input Code:
{{ReactComponent}}

Desired styling framework:
{{CSSFramework}}
```

To use a prompt, copy the template with Gisto's clipboard overlay and inject your specific parameters directly in your target AI workspace.

## Integrating AI assistant descriptions

Gisto provides a subtle AI-assisted tool inside snippet descriptions. If you add your AI provider API key in settings, you can click the optional **AI** description helper. Gisto will analyze the contents of your code file or document to automatically suggest clean descriptions and tags, making indexing fully effortless.
