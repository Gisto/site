---
title: "Is Gisto fully offline-ready?"
author: Sasha Khamkov
category: 2. F.A.Q.
published: 2026-05-29
---

Yes. Gisto uses a local-first sqlite/file database on your machine. You can create, edit, tag, and query all your code files and markdown documents without any active internet connection. Changes will automatically sync next time Gisto connects online.
