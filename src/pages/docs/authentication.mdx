## Overview

Gisto supports two authentication modes: GitHub/GitLab authentication using access tokens, or local mode using IndexedDB to store snippets locally without an account.

### GitHub

Gisto authenticates to GitHub by using a GitHub Access token. You may manually create an access token from the account settings at GitHub and login using the generated token.

**Token Storage:**

Gisto only saves the Access token in your local storage and nothing else. This token will be saved permanently until you log out, or it will expire.

### GitLab

Gisto now supports GitLab snippets with full parity to GitHub functionality.

**How to authenticate:**

1. Open Gisto login page
2. Select "GitLab" as your provider
3. Create a personal access token from your GitLab [account settings](https://gitlab.com/-/user_settings/personal_access_tokens) and paste it in the provided field

**Token Storage:**

Like GitHub tokens, GitLab access tokens are stored securely in your local storage and not shared with any external service.

### Snippet-Bin

Gisto supports [Snippet-Bin](https://github.com/sanusart/snippet-bin), a self-hosted snippet server inspired by the GitHub Gists API. This gives you full control over your data and infrastructure.

**How to authenticate:**

1. Open Gisto login page
2. Select "Snippet-Bin" as your provider
3. Paste the Snippet-Bin instance URL (e.g., `https://snippet-bin.yourdomain.com`)
4. Enter your Snippet-Bin API token

**Token Storage:**

Your Snippet-Bin instance URL and API token are saved in your local storage and not shared with any external service.

### Local Mode (No Authentication Required)

You can use Gisto without connecting to any external provider. Store snippets locally using IndexedDB.

**Benefits:**

- No account required
- Snippets are stored in your browser's local database
- You can export and import your snippets as JSON files from Settings
- Works fully offline

**How to use:**

1. Launch Gisto
2. Choose "Local Storage" or skip authentication
3. Start creating and managing snippets immediately
