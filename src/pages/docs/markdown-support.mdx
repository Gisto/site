## Overview

While Gisto is known for robust code snippet organization, it is also a highly capable **documents editor** with comprehensive **Markdown support**. This makes it the perfect repository for architectural notes, project setup guides, README wikis, and system documentation alongside your code base.

## Creating structured documents

To create a new document in Gisto:

1. Click the **New Snippet** button in the main sidebar.
2. Give your file a name ending with the `.md` or `.markdown` extension.
3. Gisto will automatically load the Monaco editor configured for Markdown markup.
4. Compose your documentation using standard GitHub Flavored Markdown (GFM).

## Multi-file documents

One of Gisto's key superpowers is **multi-file folders**. A single snippet item in Gisto can contain multiple separate files. This allows you to bundle an active code snippet directly with its Markdown implementation guide, database seed schemas, or setup notes under a single searchable record.

* Click **Add File** inside a snippet card to append additional documents.
* Blend scripts, JSON APIs, SQL structures, and Markdown READMEs in a single folder container.

## Markdown & file previews

Gisto includes native preview tabs for rich files. You can toggle between edit mode and a fully rendered preview layout for:

* **Markdown (`.md`):** Renders beautiful HTML lists, headers, code blocks, and check lists.
* **HTML (`.html`):** Renders sandbox-safe visual pages.
* **JSON (`.json`) & CSV (`.csv`):** Formats raw data structures into highly readable grids.
* **PDFs (`.pdf`):** Displays PDF reports inside Gisto.

To preview a file, click the **Preview** toggle eye icon located at the top-right of your active editor window.
